Find what is wrong with a web page before your visitors do.

Paste a page's HTML and get a fix list ordered by severity: indexing, metadata, accessibility, reading level, and structured data. The audit runs in your browser, so the HTML never leaves this tab.

Findings

Nothing audited yet. Choose Audit this page to check the sample. The audit looks at:

  • Title, meta description, and H1
  • Canonical tag and noindex directives
  • Page language, image alt attributes, link text, heading order
  • Reading grade level of the main content
  • JSON-LD structured data: syntax and expected properties

The first run downloads the audit engine, about 10 MB. Later runs are instant.

One page is a spot check. A site run finds the patterns.

Pointed at an XML sitemap, the same engine also finds broken internal links, redirect chains, duplicate titles, orphan pages, and noindex pages the sitemap still lists. It writes an HTML report, CSV files, and a SQLite database you can query.

Open the sample report for an 11 page demo site

Run it on your own site

The command line tool needs Python 3.10 or newer. Against a live site it obeys robots.txt, identifies itself, and waits between requests.

git clone https://github.com/callanspyfer/website-governance-audit.git
cd website-governance-audit
pip install -e .
webaudit --sitemap https://www.example.org/sitemap.xml --out audit-report
